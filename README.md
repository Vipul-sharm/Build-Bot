# Amazon Lex Project

## About
This project is a chatbot created using **Amazon Lex**.  
It demonstrates how to build a simple conversational bot that can respond to user queries with predefined answers.

## Features
- Handles basic user questions  
- Shows how Amazon Lex understands natural language  
- Can be tested in the Amazon Lex console  

## How to Use
1. Open the Amazon Lex console  
2. Select this bot project  
3. Type a question in the test chat window to see the response
